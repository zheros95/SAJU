# 수상학(손금·손 형태) 세부 판독 체계 — 연구 노트

- 작성일 2026-11-23. 용도: 개인용 사주/수상 웹앱의 해설 문구·설문 문항 작성 참고.
- 범위: 이미 가진 개요(4원소·9구·5대선·특수문양·2D:4D 개요)는 생략하고 **변형별 해석·유파 차이·실증 사실**만 정리.
- 전제: 수상은 과학 문헌에서 의사과학으로 분류된다(en/ko/zh 위키백과 Palmistry, Skeptic's Dictionary). 아래 "해석"은 전부 "그 전통이 그렇게 말한다"는 기술이지 사실 주장이 아니다.

## 1. 주요선의 변형별 해석

### 1.1 생명선 (Line of Life / 地紋)

| 변형(사진으로 구분) | 전통 해석 | 태그·출처 |
|---|---|---|
| 호가 크다(손바닥 중앙까지 넓게 돌며 금성구를 넓힘) | 체질 강건·활력·온정. Cheiro는 혈류(손바닥 동맥궁)로 설명, Benham은 금성구의 영역이 넓어져 그 성질이 커진다고 설명 | [확실][통설] C 3장, B 2부 7장 |
| 호가 작다(엄지 쪽에 붙어 금성구를 좁힘) | Cheiro: 섬세한 체질·활력 적음. Benham: 건조·냉담, 장수 가능성도 줄어든다고까지 서술 | [확실] C, B |
| 길다·끊김 없이 선명 | 활력·질병 저항력이 오래 유지 | [통설] C, B, JW |
| 짧다 | Benham: "활력이 온전히 유지되는 기간이 짧다"는 뜻이고 그 끝이 "주의 지점"; 양손 비교 필수(오른손이 더 길면 보강으로 읽음). 현대: 독립적·변화 많은 삶 등으로 완화 | [확실] B / [대중매체] Allure Korea 2022 |
| 깊고 가늘게 선명 vs 넓고 얕음 | 둘 다 "깊고 맑은 선"을 최상으로 침. Cheiro: 넓은 선은 근육적 힘, 가늘고 깊은 선은 신경·의지력이며 병에 더 잘 버팀. Benham: deep=활력, thin=지구력 부족(병약 단정은 금지), broad·shallow=활력 결핍 | [확실][통설] C, B |
| 사슬형·섬 | 그 구간의 건강 취약기. Cheiro는 부드러운 손에서 더 불리하다고 봄 | [확실] C, B |
| 끊김 | 겹쳐서 이어지는지, 자매선·사각형(보호)으로 "수리"되는지가 핵심 | [확실] B 2부 3장, C |
| 이중선(화성선/자매선) | 제1화성구에서 나와 생명선 안쪽을 따라감. 활력 보강·끊김 완화. Cheiro는 호전적 기질도 부여. Benham은 "아주 가까이 붙어야" 화성선이고 멀면 영향선 | [확실][통설] C 4장, B 2부 14장 |
| 끝이 월구 쪽으로 갈라짐 | Cheiro: 변화·여행 많은 삶, 선 전체가 월구로 가면 타향 정착. Benham: 끝 갈라짐은 활력의 분산(건강 관점), 넓게 벌어질수록 불리 → **유파 차이** | [확실] C 14장 / B 7장 |
| 시작점이 높다(검지 쪽) / 낮다(엄지 쪽) | 높음=자제력·야망, 낮음=성급·다툼 잦음 | [일부 유파] C |
| 위로 뻗는 잔선(노력선) | 그 시기의 분발. 목성구 쪽이면 지위 상승 욕구. 일본은 向上線·努力線으로 독립 명명 | [확실] C / [일부 유파] JW |

**"길이=수명" 속설에 대한 입장**
- Cheiro는 생명선이 "자연 원인에 의한 수명"을 예고한다고 썼다. 다만 건강선이 생명선과 만나는 지점이 더 중요하다고 단서를 붙임. [확실] C 3·10장
- Benham은 "일반론으로는 길수록 길다"면서도, 사망자 손에서 사망 나이를 지나 이어진 생명선을 다수 봤다고 인정하고, 생명선은 "활력과 타고난 건강"의 선이며 특정 시점의 죽음을 단정하지 말라고 못박음. [확실] B 7장
- 현대 수상가·대중 자료는 "수명이 아니라 체력·생활 에너지"로 정정하는 것이 주류. [통설] JW("短命の相とは限らない"), Allure Korea, 다수 영어권 가이드
- 실증: 시신 계측 연구 3건이 엇갈림 — Wilson & Mather 1974(51구) 무상관, Newrick 외 1990(100구) 유의 상관 보고, Lucas·Dhugga·Henneberg 2019(60구, Anthropological Review 82(2)) 무상관. [확실: 2019 논문 초록 요약 경유] 결론적으로 근거 없음.

### 1.2 생명선과 두뇌선의 시작 관계

| 형태 | Cheiro [C 2장] | Benham [B 2부 6장] |
|---|---|---|
| 붙어서 시작 | 민감·신중·자신감 부족, 능력을 과소평가 | 대부분의 손이 이 형. 붙은 구간이 길수록 자립이 늦고 남의 조언에 의존 |
| 오래(길게) 붙음 | — | 자기 판단을 늦게 시작. 보통 붙은 구간은 12세 무렵까지에 해당한다고 봄 |
| 살짝 떨어짐 | 최상: 독립적 사고·빠른 판단·대담. 단 "목적"이 있어야 함 | 자립·독창·용기. 좋은 표지 |
| 넓게 떨어짐 | 충동·지속성 부족·무모·흥분하기 쉬움 | 자만·무모로 변질될 위험, 좋은 조언자가 못 됨 |

- [확실] 방향은 두 저자 일치(붙음=신중·의존, 떨어짐=자립·대담). [통설]
- **불일치**: Cheiro는 "붙은 형이 민감"이라 하고, Benham은 "떨어진 형이 오히려 가장 민감(자존심 때문)"이라 한다. 문구에 "민감"을 쓸 때 한쪽만 옳다고 쓰지 말 것.
- 실측 분포 [확실] P10: 붙음(closed) 87.0%, 떨어짐(open) 7.8%, 가장자리에서만 닿음(meeting) 5.2%. 여성은 떨어짐이 12~14%로 남성(5~6%)보다 많음. → 설문에서 "떨어짐"은 소수 선택지.
- 중국식 掌型 분류의 "川字掌"은 떨어진 형, "人字掌"은 붙은 형에 해당. [대중매체] ZW

### 1.3 두뇌선 (Line of Head / 人紋)

- **직선형**(손바닥을 수평으로): 실용·상식·일관. Benham은 이것을 모든 휘어짐을 재는 기준선으로 삼음. [확실][통설] B, C
- **완만한 하강**(월구 쪽으로 부드럽게): 상상력을 "필요할 때 쓰는" 통제된 창의. [확실] C
- **깊은 하강**(월구 깊숙이/손목 쪽): 상상에 끌려다님·기분파. Cheiro는 정신적 위험까지 서술하나 구식 병리 표현이므로 앱에서는 "몰입형 상상력" 수준으로 완화 권장. [확실] C / 완화는 편집 제안
- **길이**: Benham은 긴 선=정신 활동 풍부, 짧은 선=적음으로 단순 대응하되 반드시 다른 선·유형과 함께 보라고 함. "중지 아래에서 끝=짧음, 약지 아래=보통, 소지 아래·손날까지=긺"이라는 손가락 기준 눈금은 현대 입문서 관행. [확실] B / 눈금은 [대중매체]
- **손바닥 전체를 가로지르는 직선 두뇌선**: Benham은 머리가 감정보다 우위라고 읽음. 의학의 시드니선(§7.3)과 형태가 겹치지만 수상 고전에는 "시드니선" 고유 해석이 없다(1960년대 의학 용어). [확실] B / 고유 해석 부재는 [통설]
- **끝 갈라짐**: Cheiro는 두 갈래가 대등하면 실용과 상상 사이에서 망설임(첫 직감대로 하라고 조언), Benham은 다재다능·두 관점으로 봄 → **평가가 반대**. "writer's fork / lawyer's fork"라는 이름은 현대 대중서 용어로 기원 문헌 미확인이며 "포크가 있다고 글재주가 있는 건 아니다"는 실무자 경고도 있음. [확실] C, B / 명칭은 [대중매체]
- **이중 두뇌선**: 드묾. 이중의 정신성·큰 작업량. 그러나 Cheiro 자신이 "선명한 한 줄이 더 성공적"이라 평가. [일부 유파] C
- **사슬형·섬**: 집중 지속이 어려운 시기. 두 저자 모두 질병·정신이상과 연결하나 앱에서는 사용 금지 권장. [확실] C, B
- **손 유형과의 일치**: 사각형 손엔 직선, 철학·원추·심령형 손엔 하강선이 "제격"이고, 어긋나면 그 어긋남이 읽을거리. [일부 유파] C

### 1.4 감정선 (Line of Heart / 天紋)

- **읽는 방향이 유파마다 반대**: Benham·Cheiro는 검지 쪽을 "시작"으로 쓴다("목성구에서 솟는다"). 현대 입문서·한국·일본은 소지 쪽에서 시작해 검지 쪽에서 "끝난다"고 쓴다. 위치별 의미는 같은 것을 가리키므로 문구에서는 "검지 쪽 끝"으로 통일하면 된다. [확실] B 2부 5장, C 7장

| 검지 쪽 끝의 위치 | Benham | Cheiro |
|---|---|---|
| 검지 아래(목성구) | 감상적·이상적 애정 | 구 중앙=이상이 높고 한결같음(최상급). 구 바깥 가장자리까지=맹목적 열정·실망 |
| 검지·중지 사이 | 상식적·현실적 "중간지대" | 차분하지만 깊음, 표현은 적고 희생적 |
| 중지 아래(토성구) | 관능·육체 중심 | 자기중심·냉소·표현 적음. 짧을수록 심함 |
| 세 갈래로 퍼짐 | 감상+상식+정열의 결합, 정 많음 | — |
| 손바닥을 끝까지 가로지름 | "정이 지나침". 옛 수상가의 "모든 사업 실패"를 정정 | 질투 경향 |
| 끝이 아래(두뇌선 쪽)로 처짐 | 머리가 우위 | 애정에서 실망이 잦음 |

- 세 위치의 의미 방향은 두 저자가 대체로 일치. [확실][통설]
- **곡선형 vs 직선형**: "위로 휘는 형=감정 표현이 풍부, 직선형=절제·머리 우선"은 현대 입문서 공통(영어권에선 physical/mental heart line이라 부름). 저자 원문 확인 실패. [대중매체][미확인]
- **끝 갈라짐**: Benham은 갈래 시작=친구 많고 성공적이라 봄. [확실] B
- **사슬형**: Cheiro는 변덕·바람기. Benham은 넓고 얕은 선을 변덕으로 봄. JW는 "조금 흐트러진 편이 인간적"으로 완화. [확실] C, B / [대중매체] JW
- **감정선이 안 보이고 한 줄만 있을 때**: Benham은 99% 두뇌선으로 보고 "감정선 부재=냉정"이라 단정(낙인적). Cheiro는 "엄청난 집중력·강렬함, 좋든 나쁘든"으로 읽음 → 막쥔손금 해석의 서양 내 분기. [확실] B, C

### 1.5 운명선 (Line of Fate / Saturn)

| 출발점 | Cheiro [C 5장] | Benham [B 2부 10장] |
|---|---|---|
| 손목 중앙에서 곧게 | 태양선이 함께 있으면 순탄·행운 | 별도 의미 부여 없음(출발점은 손 밑동 어디든 될 수 있다고만 함) |
| 생명선에서 | 자기 노력의 성공, 초년은 가족 사정에 매임. 갈라져 나온 지점=독립 시점 | — |
| 생명선 안쪽(금성구) | 정열적 애정이 진로 전체를 좌우(불리하게 봄) | 물질적 성공 + 가까운 친족의 도움 |
| 월구에서 | 변화 많고 타인의 호의·대중에 의존 | 이성(異性)의 조력 |
| 손바닥 중간부터 | 초년 고생 후 자수성가. 두뇌선에서 시작하면 늦게 머리로 성공 | 자기 노력. 선이 시작되는 때부터가 전성기 |

- 월구·중간 출발의 해석은 대체로 일치하고, **금성구 출발은 정반대**. [확실]
- **없음**: 옛 수상가는 "무의미한 삶"이라 했으나 Benham은 성공한 사람 다수에게 없다며 "자수성가형, 꾸준한 노력이 필요"로 정정. JW도 없는 사람이 많다고 함. [확실] B / [대중매체] JW
- **끊김·옮겨감**: 한 줄이 끝나기 전에 옆에서 새 줄이 시작(겹침)=환경·지위의 전환이고 새 줄이 좋으면 상승. 잘게 끊기면 불안정. [확실][통설] C, B
- **끝**: 지선이 향하는 구의 성질을 띰(검지 쪽=권위, 약지 쪽=명성, 소지 쪽=상업·과학). [확실] C
- Benham은 "맹목적 숙명"을 부정하고 이 선을 인과(건강·두뇌·노력)의 결과로 읽음. [확실] B

### 1.6 태양선 (Line of Sun / Apollo)

- Cheiro: 없으면 재능이 빛을 못 봄. 출발점별 — 생명선=노력으로 얻는 성공 / 운명선=직업적 인정 / 화성평원=역경 뒤 성공 / 월구=대중 인기(변동 큼) / 두뇌선=중년 이후 지적 성공 / 감정선=만년의 안락 / 구 위에만 짧게=너무 늦은 성공. [확실] C 6장
- Benham: 최선의 이름은 "Line of Capability". 예술 재능으로만 읽는 것은 오류이고, 길수록 영향이 크다. 생명선·운명선에서 나온 선은 엄밀히는 태양선이 아니라 지선. 운명선이 없을 때 이를 보완. [확실] B 2부 11장
- JW: 운명선이 선명해도 태양선이 없으면 성공이 어렵다고 서술(Cheiro 계열). [대중매체]

### 1.7 결혼선 (애정선·관계선)

- **전통(Cheiro)**: 소지 아래 손날에서 들어오는 가로선. 뚜렷한 선만 결혼, 짧은 선은 깊은 애정·성사되지 않은 혼담. 감정선에 가까울수록 이른 결혼. 아래로 처짐=배우자보다 오래 삶, 위로 휨=결혼 가능성 낮음, 끝 갈라짐=별거, 섬=그 시기의 불화. [확실] C 8장
- **Benham의 정정(1900)**: 이름부터 "애정선"으로 바꿈. 법적 혼인이 아니라 깊은 애착의 흔적이며, 개수로 결혼 횟수를 맞히는 관행을 "a most inaccurate and unscientific thing to do"라고 비판. 길이=애착의 지속, 끝 갈라짐은 "옛 수상가는 이혼이라 했으나 간섭·소원해짐 정도". [확실] B 2부 9장
- **현대**: JW "몇 번 결혼하는지는 알 수 없다(기회의 수)", 서울신문 2006 "개수와 결혼 횟수는 무관". [대중매체]
- 시기 추정: 감정선~소지 밑동의 중간을 남 35세·여 30세로 보는 일본식 눈금이 있으나 JW 스스로 "어림 수준"이라 함. [대중매체]
- 문구 권장: "깊은 관계의 수·무게"로 쓰고 횟수·이혼·사별 예언은 금지.

### 1.8 보조선 (각 2~3줄)

- **수성선(건강선/사업선/Hepatica)**: Cheiro는 수성구에서 내려오는 선으로 보고 "없는 것이 가장 좋다", 가장 잘 변하는 선이라 함. Benham은 아래에서 위로 읽고 소화·간 상태와 사업 성과의 지표로 봄. JW도 "없는 편이 건강". [확실] C 10장, B 2부 12장 → 읽는 방향이 서로 반대.
- **재운선(財運線)**: 소지 아래 짧은 세로선. 일본·한국에서 독립 항목(일본은 수성선의 별칭). Benham·Cheiro에는 독립된 "돈의 선"이 없다. [일부 유파] JW
- **직감선**: 월구에서 수성구로 가는 반원. Cheiro는 예감·생생한 꿈, Benham은 "사실상 수성선의 변형, 눈치 빠름일 수도"라며 절제. [확실] C 12장, B
- **금성대**: 옛 해석은 방탕. Cheiro는 "정신적 관능"·기분 변화, Benham은 방탕이 아니라 신경과민으로 정정. JW는 매력·예술성으로 미화. [확실] C 11장, B 2부 13장 → 시대가 갈수록 순화.
- **솔로몬의 환**: 검지 밑동을 감싸는 호. 신비학·심리 탐구의 재능(C, B), 통찰력·지도력(JW). 드묾. [통설]
- **토성환**: 중지 밑동을 감싸는 호. Cheiro는 최악의 표지(고립·실패), Benham은 "한 가지를 오래 못 함, 실패가 필연은 아님", JW는 근래 "집착을 살리면 천재성"으로도 읽음. [확실] C, B
- **여행선**: 생명선에서 월구 쪽으로 빠지는 잔선과 월구 위 가로선. 끝의 십자=실망, 사각형=보호. 중화권은 旅行線·出國線을 乾位(손날 아래쪽)에 둠. [확실] C 14장 / [대중매체] ZW
- **팔찌선(rascettes)**: Cheiro는 중요도 낮다고 명시. 3줄=건강·부·행복은 그리스 전설로 소개. 첫 줄 아치=출산 곤란 전설은 앱 사용 금지. 동양은 손목을 끊김 없이 두르면 "玉釧紋"으로 길상. [확실] C 11장, 神
- **반항선·인기선·寵愛線·向上線·放縦線**: 일본 수상의 세분 명칭. 서양 고전에는 대응 명칭이 없고 영향선(influence line)·방종선(Via Lasciva) 정도가 대응. [일부 유파] JW

## 3. 손가락

### 3.1 상징

- 검지=목성(야망·지도·자존), 중지=토성(신중·책임·고독), 약지=태양/아폴로(미감·명성·모험), 소지=수성(언변·상업·기민). [확실][통설] C 2부 3장, B 1부 18장
- 엄지=의지와 논리. 손톱 마디=의지, 둘째 마디=논리·이성, 밑동(금성구)=사랑. d'Arpentigny의 "the thumb individualises the man"을 Cheiro가 인용. [확실][통설] C, B 1부 17장
- 동양: 엄지=本命, 검지=권위·명망, 중지=심리·사상, 약지=사회·명예, 소지=기지·재능. 고전은 "四指為賓，中指為主"(중지가 주인). [대중매체] ZW / [확실] 神 「相指掌」
- Benham의 "3세계": 손톱 마디=정신, 가운데 마디=실무, 밑마디=물질. 손 전체도 손가락=정신, 손바닥 위쪽=실무, 손바닥 밑=본능으로 3분. [확실] B 1부 10장

### 3.2 길이의 기준 (앱 자동 측정과 직결)

| 대상 | 기준 | 해석 | 태그 |
|---|---|---|---|
| 검지 | 표준=**중지 손톱 마디의 중간**까지 | 길면 지배·야망, 짧으면 책임 회피 | [확실] B(표준), C(해석) |
| 약지 | 표준=**중지 손톱 마디의 중간**까지 (즉 Benham 표준에선 검지≈약지) | 길면 미감·명성욕, 지나치면 투기·도박성 | [확실] B, C |
| 검지 vs 약지 | 검지가 중지에 육박하면 지배욕 과잉. 약지가 검지보다 훨씬 길고 태양선이 좋으면 도박 기질 | — | [확실] C |
| 소지 | 표준=**약지 손톱 마디 관절(금)**까지 | 넘으면 언변·수완, 못 미치면 표현이 서툶 | [확실][통설] B, C |
| 엄지 | 손 옆에 붙였을 때 끝이 **검지 밑마디의 중간**에 닿으면 표준 | 길수록 의지·이성이 주도, 짧으면 감정·충동이 주도. 붙은 위치가 낮으면 짧아 보이니 보정 | [확실] B |
| 손가락 대 손바닥 | Benham: 긴 손가락=세부·신중·느림, 짧은 손가락=전체 파악·신속·충동 | Cheiro: 손가락≈손바닥이면 균형, 길면 이상·정밀 | [확실][통설] B 1부 15·16장, C |

- 사용자 메모의 "엄지가 검지 첫마디 중간"은 Benham식 번호(손끝부터)로는 **third phalanx=밑마디**다. 문구는 "검지 밑마디 중간"으로.
- Benham의 측정법: 손가락을 접어 손바닥 어디까지 닿는지 본다(금성구 중앙 아래~손목선이면 긴 손가락). 단 구의 높이 때문에 오차가 크다고 스스로 경고. → 관절점 좌표로 재는 앱 방식이 오히려 일관적. [확실] B
- 4원소 분류에 쓸 "손가락/손바닥" 비율의 **수치 기준은 저자 간 합의가 없다.** 앱은 자체 표본의 중앙값으로 나누고 경계 근처는 "중간형"으로 처리하는 것을 제안. [편집 제안]
- 동양 고전의 대응 구결: "只可龍吞虎，不可虎吞龍"(손가락=龍, 손바닥=虎 — 손가락이 손바닥을 이겨야 좋다), "掌長指短" 은 불리. 서양(짧은 손가락=신속·실행)과 **가치 판단이 다르다**. [확실] 神 「相指掌」
- Cheiro의 "짧은 손가락=저급" 식 서술은 19세기 인종·계급 편견이 섞인 문장이므로 인용 금지.

### 3.3 마디·손끝·엄지

- **마디(매듭)**: 매끈한 손가락=직관·충동, 마디가 굵은 손가락=분석·숙고(d'Arpentigny 기원). Benham: 손톱 쪽 관절의 매듭=정신적 질서, 가운데 관절의 매듭=물질적 질서(정리정돈). [확실][통설] B 1부 13·14장, C
- **손끝 4형**: 주걱형=활동·실용·독창, 사각형=질서·규칙·실무, 원추형=예술·감응·충동, 뾰족형=이상·몽상. Benham은 "손 전체"가 아니라 **손가락마다** 끝 모양을 보라고 함(혼합이 보통). [확실][통설] B 1부 12장, C
- **엄지 두 마디 비율**: 손톱 마디가 둘째 마디보다 약간 짧은 것이 표준. 둘째 마디가 더 짧으면 "의지가 이성을 앞섬". 둘째 마디가 잘록(waist)하면 재치·외교. [확실] B, C
- **엄지 유연성**: 뒤로 잘 젖혀짐(supple)=적응·관대·씀씀이 큼·즉흥, 뻣뻣함(stiff)=신중·절약·고집·신뢰. 두 저자 완전 일치. [확실][통설] C 2부 2장, B
- **엄지의 붙은 위치·벌어짐**: 낮게 붙고 넓게 벌어짐=관대·독립, 손에 바짝 붙음=조심·인색. [확실] B, C
- **곤봉형 엄지("살인자의 엄지")**: 두 저자 모두 격정과 연결하나 Benham은 "손의 나머지를 다 보기 전엔 단정 금지"라 유보. 의학적으로는 흔한 유전 형질(단지증 D형)로 성격과 무관 → 앱 사용 금지. [확실] B, C / 의학 설명은 [미확인: 본 조사에서 별도 검색 안 함]
- 관절점 21개로 잴 수 있는 것: 길이 비율·엄지 두 마디 비율·손가락 벌어짐 각도. 잴 수 없는 것: 마디 굵기·손끝 모양·유연성·살집 → 설문 문항으로.

## 4. d'Arpentigny 7형과 4원소형

- **계보**: d'Arpentigny 『La Chirognomie』(1839)가 손 형태 분류의 출발점(en.wikipedia). Desbarrolles 『Les Mystères de la main』(1859)가 형태학에 손금·행성 구 체계를 결합(fr.wikipedia에서 서지 확인, 체계 내용은 [미확인]). Cheiro가 7형을 그대로 대중화. Benham은 손 전체 유형 분류를 버리고 "손끝 모양 + 7개 구(丘) 유형"으로 대체. [확실] C 2부 1장, B 1부 12장
- **7형** [확실] C: ① 원시형(짧고 두꺼움, 본능) ② 사각형(유용·실무·규칙) ③ 주걱형(활동·발명·비관습) ④ 철학형(마디 굵고 김, 분석) ⑤ 원추형(예술·충동) ⑥ 심령형(가늘고 뾰족, 이상·비현실) ⑦ 혼합형.
- **4원소형**: Fred Gettings 『The Book of the Hand』(1965)가 정리했다는 것이 통설. 손바닥 모양(정사각/직사각) × 손가락 길이(짧음/김)의 2축. 흙=정사각+짧음, 공기=정사각+김, 불=직사각+짧음, 물=직사각+김. [통설] 다수 2차 자료 일치, 원서 [미확인]

## 5. 동양(중국·한국·일본) 수상

### 5.1 문헌 계열

- 『太清神鑑』(四庫全書 수록) → 『神相全編』(陳摶 전·袁忠徹 정정, 명대 집성) → 청대 『古今圖書集成』 藝術典 相術部에 전재. 『麻衣相法』은 麻衣道者에 가탁한 후대 집성으로 내용이 대부분 겹친다. [확실] zh.wikisource / 가탁설은 [대중매체]
- 일본은 『神相全編』의 간약본(3책 내외)이 유통됐고(일본 국문학연구자료관 해제), 근현대에 서양식(구·선·流年法)이 주류가 되었다. [대중매체]
- 고전의 손 보는 순서: "先看八卦，次察五行" — 구역(궁)과 형태·살·색이 먼저고 선은 그다음. 선 중심인 서양과 우선순위가 다르다. [확실] 神 「玉掌記」

### 5.2 삼재문(三才紋)과 서양 3대선

| 고전 명칭 | 위치(고전) | 고전의 의미 A: 「論掌紋」 (太·神 공통) | 고전의 의미 B: 「相三才」 (神) | 현대 대응 |
|---|---|---|---|---|
| 天紋(上畫) | 맨 위, 火(離) 자리 | 君·父를 상징, **貴賤** | 根基 | 감정선 |
| 人紋(中畫) | 가운데, 明堂 | 賢愚를 상징, **貧富** | 福德 | 두뇌선 |
| 地紋(下畫) | 아래, 土 자리 | 臣·母를 상징, **壽夭** | 財祿 | 생명선 |

- 위치 대응(天=감정선, 人=두뇌선, 地=생명선)은 [통설](TVBS 건강, 중화권 다수). 그러나 **의미는 대응하지 않는다.** 고전의 天紋은 애정이 아니라 귀천·부친이다. 현대 중화권 매체는 서양식 의미를 天·人·地 이름에 그대로 붙여 쓴다.
- 같은 『神相全編』 안에서도 A와 B가 다르다(편집 집성서라 내부 불일치).
- 地紋=壽夭는 서양의 "생명선=수명" 속설과 같은 방향의 고전 근거다. 다만 고전은 "三紋瑩淨" 즉 세 선이 맑고 끊김이 없는지를 본다(길이가 아님).
- 고전은 세 선이 태중에서 주먹을 쥔 채 형성된다고 설명한다 — 태아기 형성이라는 점은 현대 발생학(§7.1)과 우연히 일치.
- 중화권 掌型: 人字掌(생명·두뇌선 붙음), 川字掌(세 선이 따로), 斷掌(한 줄). [대중매체] ZW

### 5.3 팔괘·구궁 배치

- 후천팔괘를 손바닥에 얹고 손가락 쪽을 남(離), 손목 쪽을 북(坎)으로 둔다. [神]의 「根基所屬」이 각 궁의 소관·오행·지지를 명시:

| 궁 | 고전 소관 [확실] 神 | 손바닥 위치(통용 도해) | 겹치는 서양 구(근사) |
|---|---|---|---|
| 巽 | 財帛·祿馬 (木, 辰巳) | 검지 아래 | 목성구 |
| 離 | 官祿 (火, 午) | 중지(~약지) 아래 | 토성구·태양구 |
| 坤 | 福德·母 (土, 未申) | 소지 아래 | 수성구 |
| 兌 | 奴僕·子息 (金, 酉) | 손날 가운데 | 제2화성구 |
| 乾 | 天門·父 (金, 戌亥) | 손날 아래쪽 | 월구 |
| 坎 | 海門·根基(조상 터전) (水, 子丑) | 손목 바로 위 가운데 | (지구·손바닥 밑동) |
| 艮 | 田宅·墳墓 (土, 丑寅) | 엄지 밑동 아래쪽 | 금성구 하부 |
| 震 | 妻妾·立身 (木, 卯) | 엄지 쪽 가운데 | 금성구 상부·제1화성구 |
| 明堂 | 中央 五黃, "目下之吉凶"(당장의 길흉) | 손바닥 한가운데 | 화성평원 |

- 손가락 밑 세 봉우리가 巽·離·坤이라는 점은 [神] 「相三奇」("坤離巽突起三肉峰")로 확인. 나머지 위치는 후천팔괘 방위 논리와 통용 도해에 따른 것이며, 대중 자료끼리 艮·震의 위아래가 엇갈린다(看中國 2023 기사는 艮을 생명선 기점, 震을 엄지 위쪽 봉우리로 설명). [통설이나 도해 불일치]
- 궁의 소관도 자료마다 다르다(震=妻妾 vs 兄弟 등). 앱에서 쓰려면 [神] 원문 기준으로 고정할 것.
- 판독 기준은 선이 아니라 그 구역이 "도톰한가(豐·起)/꺼졌는가(陷)/잔금으로 깨졌는가(破)"다. 예: 巽 봉우리가 가장 높으면 "旺財, 初年發福", 離가 "破陷"이면 영화가 오래 못 감. 사진 설문으로 옮기기 쉬운 것은 巽·離·坤 세 봉우리의 도톰함 정도.

### 5.4 오행 손형

- 고전의 五行形은 본래 **전신·얼굴** 분류다: "木瘦金方水主肥", "土形敦厚背如龜", "上尖下闊名為火". [확실] 『古今圖書集成』 藝術典 제632권(神相全編 계열)

- 앱 제안: 양손을 받는 것이 모든 유파와 충돌이 없다. 한 손만 받는다면 "주로 쓰는 손=현재"가 충돌이 가장 적고, 남좌여우는 선택 옵션으로.

## 7. 실증 사실 (과장 없이)

### 7.1 손바닥 주름의 형성 시기
- 손바닥 굴곡선은 태아기 초기에 생긴다. Popich & Smith 1970(J Pediatr 77:1017): 임신 7~14주. Kimura & Kitagawa 1986(Anat Rec): 6~20주 태아 160례 관찰, 대체로 손의 굴곡 운동과 독립적으로 발달. 엄지 쪽 주름(생명선)이 약 8주로 가장 먼저라는 2차 인용이 있으나 10주설도 있음. MedlinePlus: "대개 12주까지". [확실: 초록·2차 요약 수준, 원문 전문 미열람]
- 원인 논쟁: "관절이 접히는 면을 따라 2차적으로 생긴다"(Popich & Smith) vs "운동 이전에 미리 형성"(Kimura, Bali & Chaube 1971). 어느 쪽이든 "출생 후 손을 쥐는 습관으로 새겨진다"는 설명(JW 등)은 부정확. [통설]
- 유전 영향이 있고(Tay 1979, Ann Hum Genet), 좌우 손이 다를 수 있다. [확실] P10 참고문헌·ko.wikipedia

### 7.2 단일 손바닥 가로주름 (막쥔손금·일자손금)
- 일반 인구 빈도: 약 1.5~3%(en.wikipedia가 교과서 인용), 약 30명 중 1명·남성이 2배(MedlinePlus). 동아시아·아메리카 원주민에서 더 흔함. [통설]
- 집단별 인용치: 일본 4%, 독일 2.8%, 스위스 1.2%, 에티오피아 대학생 5.0%(Belay 외 2022 및 그 인용). [확실: 2022 논문]
- 한국: P10은 **손바닥 기준 12.6%**(남 오른손 15.6%·왼손 12.5%, 여 오른손 11.4%·왼손 7.5%). 가지가 붙은 변형까지 넣은 넓은 정의이고 사람이 아닌 손바닥 단위라 위 수치와 직접 비교 불가. 그래도 "한국에서는 드물지 않다"는 근거는 된다. [확실] P10 표2
- 의학적 의미: 다운증후군의 약 45%에서 보이고 태아알코올증후군·여러 염색체 이상에서 빈도가 높다. 그러나 건강한 사람에게도 흔해 **그 자체로는 진단·예측 가치가 없다**(en.wikipedia, MedlinePlus). "simian"이라는 말은 비하적이라 퇴출 중. [확실][통설]

### 7.3 시드니선·수원손금
- 시드니선: 근위 가로주름(두뇌선)이 손날 끝까지 뻗은 형. Purvis-Smith & Menser가 호주에서 보고(Lancet 1968; JAMA 1969 — 선천성 풍진 아동 100명 중 27명). 이후 소아 백혈병·다운증후군에서 빈도가 높다는 보고(BMJ 1973; 방글라데시 연구 다운증후군 23% vs 대조 2%). [확실: 초록 수준]
- 일반 인구 빈도는 정의·집단에 따라 0.2~9%로 폭이 크다. 한국 2.5%(P10), 에티오피아 1.9%. 역시 대부분은 정상 변이. [확실] P10, Belay 2022
- 수원손금: 한국 연구진이 명명한 변형. P10에서 0.5%, 남성에서만. [확실]

### 7.4 2D:4D의 재현성 논란
- 평균적으로 남성이 여성보다 비율이 낮다는 성차 자체는 반복 관찰된다. 그러나 집단 간 차이가 성차보다 크다(Manning 본인 발언). [확실] en.wikipedia Digit ratio
- "태아기 테스토스테론의 지표"라는 전제가 흔들린다: 대표 근거 Lutchmaya 2004의 직접 재현 시도(Richards 외 2021, 66명)는 무상관, 탯줄혈 호르몬과도 무상관(Hollier 2015), 안드로겐 수용체 유전자 연관은 메타분석에서 지지되지 않음(Voracek), 전장유전체 분석도 확증 못 함(Warrington 2018). 지지 근거는 선천성 부신과형성 환자의 낮은 비율, 생쥐 실험(Zheng & Cohn 2011). [확실: 위키백과·검색 요약 경유]
- 통계적 비판: 손가락 길이에 따른 상대성장(allometry)의 부산물일 수 있음(Kratochvíl & Flegr 2009). 측정법(직접·복사·X선, 손바닥 쪽·손등 쪽)에 따라 값이 달라지고 유의한 것만 보고될 여지. [확실]
- Science 2019(Leslie)의 비판 기사, BMJ 2021(Smoliga 외)의 "2D:4D와 행운" 풍자 연구가 재현성 문제의 상징. [확실]
- 결론: 개인의 성격·적성·성향을 2D:4D로 말하는 것은 근거가 없다. 앱에서는 "재미 요소"로만.

### 7.5 "손금은 변한다"는 주장
- 수상가 쪽 주장: Benham(1년 사이 없던 두뇌선이 생긴 사례), Cheiro(건강선이 가장 잘 변함), JW(운명선 끝·방종선은 변함), ZW(10~20대에 변동 큼). [확실: 그렇게 썼다는 사실]
- 실증: 같은 사람의 손바닥 선을 장기간 계측 추적한 연구는 이번 조사에서 찾지 못했다. 주 굴곡선은 해부학 문헌에서 "permanent"로 기술되고(Belay 2022) 법과학에서 개인 식별에 쓸 만큼 지속적이다. 잔금은 노화·피부 탄력 저하·손 사용에 따라 늘거나 흐려질 수 있다는 설명은 그럴듯하나 계측 근거는 [미확인].
- 따라서 "주선은 거의 안 변하고 잔금은 변할 수 있다"까지만 말할 수 있고, "운이 바뀌면 선이 바뀐다"는 근거 없음.

### 7.6 예측력 검증
- 생명선 길이와 사망 연령: §1.1의 세 연구. 현재 근거 없음.
- 심리학자 Ray Hyman: 손금 풀이를 일부러 정반대로 해 줘도 의뢰인 반응이 똑같이 좋았다는 경험을 보고 — 적중감은 선이 아니라 콜드 리딩·바넘 효과에서 온다는 고전적 사례. [통설] en.wikipedia Palmistry

## 8. 수상가 스스로 부정하거나 근거가 없는 속설

1. **생명선이 짧으면 일찍 죽는다** — Benham이 단정 금지, 현대 수상가 다수가 부정, 시신 연구도 지지 안 함. (§1.1)
2. **결혼선 개수=결혼 횟수** — Benham이 1900년에 이미 "부정확·비과학적"이라 비판. 일본·한국 매체도 부정. (§1.7)
3. **결혼선 끝이 갈라지면 이혼** — Benham: 옛 해석일 뿐, 간섭·소원 정도.
4. **자녀선으로 자녀 수·성별을 안다** — Cheiro는 장 제목으로까지 내세웠으나(9장) 검증된 바 없음. [확실: 목차] 앱 사용 금지 권장.
5. **운명선이 없으면 불운·무의미한 삶** — Benham이 성공한 사람들의 손을 근거로 부정.
6. **태양선=예술 재능·부와 명성** — Benham이 대표적 오독으로 지목.
7. **금성대=방탕** — Cheiro·Benham 모두 부정(신경과민·정신적 감수성).
8. **건강선이 뚜렷하면 건강하다** — 전통은 반대(없는 것이 최상). C, JW
9. **왼손이 심장에 가까워서 왼손을 본다** — Benham 부정.
10. **남자는 왼손, 여자는 오른손** — 서양 고전에 없음, 일본 수상가도 부정하는 이가 있음. (§6)
11. **날짜·행운의 날·이름 이니셜까지 맞힌다 / 현재 나이를 손에서 읽는다** — Benham이 사기로 규정.
12. **막쥔손금=천재·대박(한·일) / 斷掌=부모를 극함(중화권)** — 같은 형태에 문화권마다 정반대 의미. 의학적으로는 대부분 정상 변이. (§5.6, §7.2)
13. **"살인자의 엄지"** — Benham조차 단정 금지. 유전 형질.
14. **팔찌선 첫 줄이 솟으면 출산이 어렵다** — Cheiro가 "전설"로 소개한 것.
15. **토성환·섬·십자 등 "흉상" 하나로 인생이 결정된다** — Benham: 단일 표지로 단정하지 말고 손 전체와 조합하라는 것이 책 전체의 원칙.
16. **손금 성형으로 운을 바꾼다** — JW가 소개하는 수상가들의 부정론.
17. **손금은 손을 쥐는 버릇으로 생긴다 / 운에 따라 주선이 바뀐다** — 태아기 형성, 추적 근거 없음. (§7.1, §7.5)
18. **2D:4D로 성격·성향을 안다** — 재현성 문제. (§7.4)

## 9. 유파 간 불일치·주의할 점

- **감정선을 읽는 방향**이 고전(검지→손날)과 현대·한일(손날→검지)이 반대. 문구는 "검지 쪽 끝/소지 쪽 끝"으로 중립화.
- **건강선을 읽는 방향**도 Cheiro(위→아래)와 Benham(아래→위)이 반대.
- **생명선·두뇌선 시작**: "민감함"을 붙은 형(Cheiro)에 줄지 떨어진 형(Benham)에 줄지 갈림. 공통분모는 붙음=신중, 떨어짐=자립.
- **두뇌선 끝 갈라짐**: 우유부단(Cheiro) vs 다재다능(Benham).
- **운명선의 금성구 출발**: 애정이 진로를 흔듦(Cheiro) vs 친족의 도움과 물질적 성공(Benham).
- **생명선 끝의 월구 갈래**: 여행·이주(Cheiro) vs 활력 분산(Benham).
- **유년 눈금**: 같은 교차점이 유파에 따라 5~10년 차이. 나이 단정 금지.
- **손가락 길이의 가치 판단**: 서양은 중립(긴=정밀, 짧은=신속), 동양 고전은 긴 손가락을 일방적으로 길하게 봄.
- **오행과 4원소는 다른 체계**: 특히 水形(둥글고 살찜)≠물형(길고 가늚). 火形도 출처마다 다름.
- **삼재문의 의미**: 위치 대응은 통설이나 고전 의미(귀천·빈부·수요)는 서양 의미(감정·지성·활력)와 다르고, 고전 내부에서도 두 설이 있음.
- **팔괘 위치 도해**는 대중 자료 간 艮·震이 엇갈림. 고전 원문은 소관만 명시하고 좌표는 그림에 의존.
- **고전 저자의 병리·인종·계급 서술**(Cheiro의 "저급한 손", 두 저자의 광기·범죄 표지, Benham의 "감정선 없음=부정직")은 근거 없는 낙인이므로 앱 문구에서 배제.
- **Benham의 마디 번호**는 손끝부터. 번역 시 뒤집히기 쉬움.
- **출처 품질**: 서양 고전 2종과 동양 고전 2종은 원문 확인. Gettings(1965)·Desbarrolles·d'Arpentigny 원서, 西谷泰人의 유년 눈금, "physical/mental heart line"·"writer's fork"의 원전, 오행 손형의 최초 문헌은 **확인하지 못했다**. 일본·한국·중화권 현대 해석은 거의 전부 대중매체다.
- **의학 수치**는 정의(변형 포함 여부)·단위(사람/손바닥)·집단에 따라 크게 달라진다. 앱에 쓸 때는 "드물지 않은 정상 변이" 수준으로만.
