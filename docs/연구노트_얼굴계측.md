참고(단일 치수의 CV, 27개 집단 평균; Fang 외 2011, Plast Reconstr Surg, PMC3074358, 요약 도구로 읽음): zy–zy 4.2–4.6%, ex–ex 4.9–5.1%, go–go 5.1–5.6%, en–ex 6.5–6.9%, al–al 7.2–7.8%, ch–ch 7.6–7.9%, n–sn 7.0–7.6%, sn–gn 7.8–8.0%, en–en 8.7–8.8%.
해석: en–en/ex–en의 집단 차(약 +20%)는 개인 간 CV(8–11%)의 약 2배 → 보정하지 않으면 한국인 대부분이 "눈 사이가 넓다"로 판정될 크기. 반면 zy–zy/n–gn 차(+5%)는 CV(5–6%)의 1배 이하.

## 4. 한계와 주의
1. **핵심 1차 문헌 미확인**: Farkas 2005·Choe 2004 원문 표는 유료/봇 차단으로 못 읽음. Farkas 백인 값(W3)은 전부 2차 인용이고 표본 수도 미확인. Farkas 2005에는 한국인 집단이 없음(초록·2차 자료 기준).
2. **한국 남성 연부조직 자료 부족**: 입술·인중·턱·3D 눈 계측은 한국 여성(K1, K2) 위주. 남성 배수는 중국 자료(C1, C2)나 K3·K5(초록)에 의존.
3. **폭 치수는 방법 의존이 매우 큼**: 3D의 zy–zy는 연구마다 정의가 달라 K2 147.2 vs W5 110.7처럼 비교 불가. 캘리퍼는 연부조직을 눌러 3D보다 작게 나옴(go–go 백인 91–120). 그래서 zy–zy·go–go가 들어간 비율은 같은 프로토콜 쌍(C1÷W2, K4÷W2)만 신뢰.
4. **Size Korea 3D(K4) 품질 의문**: 입 폭 SD 8, 동공 간 거리 69(타 자료 61–65), 청소년 포함(2023판 20세 미만 25%). 같은 DB로 Seo 외 2020(Saf Health Work 11:71)은 성인 얼굴 폭 150.1±9.7 / 147.1±10.1을 보고해 K4(137.6 / 133.2)와 불일치.
5. **동아시아 ≠ 한국**: C1·C2·C3는 중국인. C2 중국 표본은 46명(독일 거주)으로 작음.
6. **랜드마크 정의 차**: 얼굴 높이는 n–gn / se–me / n–me, 아래 얼굴은 sn–gn / sn–me가 섞여 있음(표에 ※·괄호 표시). 몽고주름이 있으면 겉으로 보이는 눈구석이 실제 en보다 안쪽·아래로 찍혀 영상 기반 en–en이 더 커질 수 있음.
7. **W1 합산값**: 3DFN은 연령별 표만 제공 → 18–30세를 n 가중 평균, SD는 연령 내 분산+연령 간 평균 차를 합산해 계산. C2 기울기는 CT_2D(Ex–En–반대쪽 En 각)를 180°에서 뺀 환산값.
8. **CV는 ρ 가정에 의존**: 실제 상관 자료 없음. 부분/전체 비율(sn–gn/n–gn, 턱/sn–gn)은 계산값이 과대, 직접 보고된 지수 SD(W3, C2, W5)가 더 믿을 만함.
9. **시대·연령 차**: Farkas 계측은 1970–80년대 캐나다, W2는 18–66세 근로자(평균 연령 높음), K1은 20–39세. 연령이 높을수록 코 폭·입 폭·인중이 커짐(K1 본문).
10. **300-W 평균 형상 = 백인 평균은 아님**: 본 표의 배수는 "백인 계측 규준 대비"이므로, 소프트웨어 기준값에 그대로 곱하기 전에 300-W 평균 형상에서 같은 비율을 직접 계산해 백인 값과 맞는지 확인 필요.
