# 전통 사주 명리 분석기

음력/양력 생년월일과 태어난 시간으로 사주팔자를 뽑아, 전통 명리학(자평명리) 기반으로
명식·대운·세운·재물/직업/연애/건강운을 분석해 보여주는 웹앱.

## 실행 방법

ES 모듈을 쓰기 때문에 HTML 파일을 그냥 더블클릭하면 안 되고, 로컬 서버가 필요해.

```bash
cd saju-app
python3 -m http.server 8000
```

그 다음 브라우저에서 **http://localhost:8000** 접속.
(VS Code를 쓰면 "Live Server" 확장으로 index.html을 열어도 됨)

## 기능

- **입력** — 혼자 보기 / 궁합 보기 모드 · 양력/음력(윤달) · 시간(모름 가능) · 성별
- **오늘의 운세** — 그날의 일진(日辰)과 길흉, 내 사주와의 작용 (결과 상단 배너)
- **명식·종합** — 사주팔자 8글자, 십성(十神), 십이운성, 지장간, **합·충·형**, 오행 균형,
  신강·신약, 격국, 용신·희신, 신살(神煞), 일간으로 본 본성
- **이때까지의 사주** — 지나온 대운 흐름 통변
- **올해 사주** — 그해 세운(歲運) 분석
- **앞으로 10년** — 현재·다음 대운 + 대운/세운 길흉 타임라인
- **운세** — 재물·직업·연애·건강운 (점수 게이지 + 해설)
- **궁합(2인)** — 두 사람의 일간·배우자궁·오행 보완·십성 관계 종합 점수
- **관상** — 얼굴 사진(카메라 촬영 또는 앨범)에서 얼굴 메시 478점을 인식해 윤곽·눈썹·눈·코·입·턱의 비율 22개 항목을 재고, 평균에서 벗어난 부위를 고전 상서 근거와 함께 풀이. 이마·귀 등 못 재는 부위는 선택 설문
- **수상** — 손 사진에서 손 모양(4원소)과 손가락 길이를 자동 측정, 손금은 사진 위 안내선을 보며 고르는 설문(선의 굵기·시작·끝 위치, 보조선·언덕)
- **PDF로 저장** — 분석 결과 전체를 A4 PDF 한 파일로 저장

## 관상·수상의 근거와 한계

- 고전 풀이는 명대 《神相全編》(마의·진희이 계열 글 수록)과 《靈樞》, 서양 수상은 Benham(1900)·Cheiro(1916)를 따른다. 고전에 근거가 없는 풀이는 화면에 '통속 해석'이라고 밝힌다.
- 수명·결혼 횟수·자녀 수·형극·성차별 구절은 원전에 있어도 옮기지 않는다.
- 얼굴 기준값은 한국인 공개 인물 사진 중 정면·무표정 60장, 손 기준값은 공개 손 사진 51장을 같은 방식으로 재서 얻은 평균과 편차다. 표본이 작아 '평균에서 얼마나 벗어났는지' 보는 눈금으로만 쓴다.
- 손금 선은 자동 인식하지 않는다. 사진 위 점선은 관절 위치로 어림한 안내선이다.

## 해석 원칙 (옵시디언 wiki/사주 반영)

- **일간(日干) 중심**으로 보고, **격국·억부·조후를 통합**한다.
- **신살은 보조 지표**로만 쓴다(맹신 금지).
- 대운(10년 큰 흐름) → 세운(1년 날씨) 순으로 대입하며,
  용신·희신이 들어오는 운을 길(吉)로 본다.

## 검증

```bash
node tests/test_solar_terms.mjs   # 절입시각 84건(KASI 2023~2028 + 국립천문대 2026) 1분 이내
node tests/test_engine.mjs        # 음력 없는 날짜 거부·데이터 구멍 보정·입춘 경계·대운 교체일
node tests/test_stage2.mjs        # 손금 판단 보류·통합 비교 판정(일치/상충/판단 불가)·시각 미상 민감도
node tests/test_stage3.mjs        # 판단 기록 — 세력 등급, 식상생재·관인상생의 성립/조건부/불성립
node tests/test_face_palm.mjs     # 관상·수상 — 정면화 보정, 22개 항목 양방향 판정, 품질 게이트, 판단 보류, 금지 표현
```

## 주의

전통 명리 이론에 근거한 **참고용 해석**이며, 통계적·과학적으로 증명된 것이 아니다.
양력 기준 **1900~2050년** 출생자만 계산된다.
