# 전통 사주 명리 분석기

음력/양력 생년월일과 태어난 시간으로 사주팔자를 뽑아, 전통 명리학(자평명리) 기반으로
명식·대운·세운·재물/직업/연애/건강운을 분석해 보여주는 웹앱.

## 실행 방법

ES 모듈을 쓰기 때문에 HTML 파일을 그냥 더블클릭하면 안 되고, 로컬 서버가 필요해.

```bash
cd saju-app
python3 -m http.server 8000
```

그 다음 브라우저에서 **http://localhost:8000** 접속.
(VS Code를 쓰면 "Live Server" 확장으로 index.html을 열어도 됨)

## 기능

- **입력** — 혼자 보기 / 궁합 보기 모드 · 양력/음력(윤달) · 시간(모름 가능) · 성별
- **오늘의 운세** — 그날의 일진(日辰)과 길흉, 내 사주와의 작용 (결과 상단 배너)
- **명식·종합** — 사주팔자 8글자, 십성(十神), 십이운성, 지장간, **합·충·형**, 오행 균형,
  신강·신약, 격국, 용신·희신, 신살(神煞), 일간으로 본 본성
- **이때까지의 사주** — 지나온 대운 흐름 통변
- **올해 사주** — 그해 세운(歲運) 분석
- **앞으로 10년** — 현재·다음 대운 + 대운/세운 길흉 타임라인
- **운세** — 재물·직업·연애·건강운 (점수 게이지 + 해설)
- **궁합(2인)** — 두 사람의 일간·배우자궁·오행 보완·십성 관계 종합 점수
- **이미지로 저장** — 분석 결과 전체를 PNG 한 장으로 저장

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` · `style.css` · `app.js` | 화면(UI)과 렌더링 |
| `saju_engine.mjs` | 명리 계산 엔진 — 십성·십이운성·지장간·신강약·용신·격국·대운·세운·신살 |
| `saju_text.mjs` | 통변(해석) 텍스트 생성 |
| `saju_descriptions.mjs` | 일간(日干)별 성격 데이터 |
| `manseryeok.mjs` | 만세력 라이브러리(절기·진태양시 보정 포함, 1900~2050 지원) |

## 해석 원칙 (옵시디언 wiki/사주 반영)

- **일간(日干) 중심**으로 보고, **격국·억부·조후를 통합**한다.
- **신살은 보조 지표**로만 쓴다(맹신 금지).
- 대운(10년 큰 흐름) → 세운(1년 날씨) 순으로 대입하며,
  용신·희신이 들어오는 운을 길(吉)로 본다.

## 주의

전통 명리 이론에 근거한 **참고용 해석**이며, 통계적·과학적으로 증명된 것이 아니다.
양력 기준 **1900~2050년** 출생자만 계산된다.
